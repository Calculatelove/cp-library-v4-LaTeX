% 代码卡片与引用块的前后距（用户确认），由 shared/code.tex 的 book-box-spacing 使用。
% 前距从上一行文字的底量到盒顶，盒与盒之间也取这个距离，紧跟标题时不加；
% 盒后把 \prevdepth 归零，下一行按段距与行距接排，另加后距。两者使正文与盒、盒与盒之间的空白一致。
\newlength{\BookBoxBeforeSkip}
\setlength{\BookBoxBeforeSkip}{9.5pt}
\newlength{\BookBoxAfterSkip}
\setlength{\BookBoxAfterSkip}{0pt}
