# 导言区

本目录集中管理宏包、各版版式与自定义接口。修改约束与验收范围见 `AGENTS.md`，正文中的写法见根目录的 `WRITING.md`。

## 文件

| 文件或目录 | 职责 |
| --- | --- |
| `packages.tex` | 加载宏包并维护加载顺序：中文、OpenType 数学、图片、颜色、删除线、页面与分栏、标题、页眉、列表、目录、minted、tcolorbox 与超链接 |
| `layout-portrait.tex` | 竖版参数，以及一级标题前分页、页眉取当前一级标题、目录标题居中等竖版专用的做法 |
| `layout-landscape.tex` | 横版参数；双栏机制由 `shared/twocolumn.tex` 提供 |
| `layout-code.tex` | 代码版参数，目前取值与横版相同，单独维护 |
| `shared/` | 三版共用的实现：字体、配色、目录条目、双栏机制、代码样式与扉页，见其 README |
| `mystyle.tex` | 四个自定义接口，见下文 |
| `fonts/` | 项目内的单色符号字体及其许可，见其 README |
| `tests/` | 接口与各版版式的样张及 PDF 检查，见其 README |

## 载入方式

三个入口依次加载：

```latex
\input{preamble/packages.tex}
\input{preamble/layout-portrait.tex}
\input{preamble/mystyle.tex}
```

横版、代码版把第二行换成 `layout-landscape.tex`、`layout-code.tex`。各版布局再按 `shared/README.md` 列出的顺序载入共用实现。入口中与排版有关的只有这三行。所有路径相对项目根目录，加载本目录的文件不会切换工作目录。宏包能加载，不等于接口或整本笔记能编译。

## 三个版本

视觉参数的具体取值以各版布局、共用实现和 `mystyle.tex` 为准，这里只记录结构、行为与设计理由。

- 竖版：A4 纵向单栏。一级标题另起页；章首页无页眉，其他页的页眉为当前一级标题；页码居中。目录单栏，标题居中。
- 横版：A4 横向双栏。章节在栏内连续排版，章末不平衡两栏；页眉为页顶所在的一级标题。目录单独起页，标题通栏居中，条目分两栏。
- 代码版：版式同横版，只收录代码及其所属标题；入口由 `scripts/generate-code.py` 生成，见 `scripts/README.md`。
- 三版都有扉页：书名、英文书名、作者、配图，以及底部的仓库地址与最新一次提交的信息。外观在 `shared/titlepage.tex`，各版用 `\TitlePageSetup` 给出版面参数；书名等元信息写在入口。

## 自定义接口

正文中的用法见 `WRITING.md`。外观与行为如下（用户确认）：

| 接口 | 外观与行为 |
| --- | --- |
| `\Highlight{内容}` | 接近 HTML `<mark>` 的黄色高亮，无额外内边距。不可拆分的行内短语框，可含粗体与行内公式 |
| `\InputCode[标题]{语言}{路径}` | 带浅灰标题栏、细边框与圆角的 minted 代码卡片。左侧按语言显示单色 Nerd Font 图标，不显示语言标签。默认取路径中的文件名作标题，给出标题时以标题为准。代码区不随文件名缩进。跨页时续页不重复标题，只在首尾保留圆角。行号与前后距见“设计决定” |
| `quoteblock` 环境 | 浅灰背景、左侧竖线、直角。可跨页，保留所在版式的段间距与首行缩进；前后距与代码卡片相同。不要求嵌套，标准 `quote` 不变 |
| `\Separator{}` | 相当于 HTML `<hr>` 的灰色横线，与上下文字保持留白，宽度随所在容器，不分页 |

图标目前覆盖 C、C++、Python、Bash、Makefile 及其别名，其余语言用通用的代码文件图标；码位依据 [Nerd Fonts 的 glyphnames.json](https://github.com/ryanoasis/nerd-fonts/blob/master/glyphnames.json)。各语言的代码外观可以用 `\setminted[语言]{…}` 调整。

## 设计决定

以下由用户确认或批准。实现与具体取值见括号中的文件。

- 字体：中文正文用宋体 Songti SC，标题与导航用苹方 PingFang SC，粗体为 Semibold；西文正文用 Latin Modern Roman 的静态字形；数学用 Latin Modern Math，STIX Two Math 只用于对照样张（`shared/fonts.tex`）。
- 中文双引号（用户确认）：保留正文输入的 `“”`，在正文罗马字体族中按西文半角左右标点处理，使用 Latin Modern Roman 的对应字重与字形；宋体引号偏小，用户更喜欢双反引号写法的效果。规则同时适用于列表、引用块、高亮及宋体目录条目；苹方标题、导航、代码卡片标题与 Maple 行内代码、代码块保留原分类。按字体选择局部切换，不逐个环境打补丁，也不全局改变其他标点（`shared/fonts.tex`）。
- 代码字体：代码块与行内代码都用 Maple Mono NF CN，关闭连字，启用 cv01 与 cv32–cv37；代码正文字号三版统一。普通 minted 片段默认不显示行号，长行折行；标题栏用苹方 Medium（`shared/fonts.tex`、`shared/code.tex`）。
- 行号（用户确认）：仅 `\InputCode` 在卡片左边框外悬挂行号，沿用代码字体，正体、灰色、右对齐；不压缩代码宽度，便于双栏查阅。每个文件从 1 开始，空行也显示编号，折行只在首个视觉行显示编号，跨页与跨栏连续（`mystyle.tex`）。
- 代码配色：名称与标点用深灰，关键字、类型、数字与预处理用灰蓝，字符串用灰绿，注释用灰色。不用斜体，也不用粗体区分 token；C++ 另把 `vector`、`string`、`pair` 当作类型名（`shared/colors.tex`、`shared/code.tex`）。
- 标题：竖版的四、五级标题与正文同字号，用苹方 Semibold 独立成行（`layout-portrait.tex`）。
- 列表（用户确认）：二级无序列表用空心圆点 `\textopenbullet`（U+25E6）；Latin Modern 中它与一级的实心圆点 `\textbullet` 外框相同，两级只差填充。二级列表不加上下间距，子项紧随父项：沿用一级间距会让父项到首个子项反比同级条目之间还远（`layout-<版本>.tex`）。
- 卡片与引用块的前后距（用户确认）：盒顶距上一行文字的底为盒前距，盒与盒之间也是这个距离；盒后把 `\prevdepth` 归零，下一行按段距与行距接排，另加盒后距，后接标题时盒底相当于上一行的基线。紧跟标题的盒由 tcolorbox 处理。未采用 tcolorbox 默认的平衡间距：它使盒与盒之间比正文与盒之间更近，盒后的标题也比正文后的标题近（`layout-<版本>.tex`、`shared/code.tex`）。
- 分隔线（用户确认）：横线按正常行距排在上一行之后，下方另加留白，使上下文字到横线的视觉距离接近。未采用上下各加一整行的做法：实际留白比二级标题上方还大（`mystyle.tex`）。
- 目录：显示到三级；书签到五级，初始只显示一级（二至五级闭合）。一级用苹方 Semibold；二、三级用宋体配 Latin Modern Roman，带点线；缩进随层级递增，并按中文字宽度计算；父条目不与首个子条目分开（`shared/toc.tex`）。
- 双栏：保留较宽松的 `emergencystretch` 设置，试过缩小后撤回；页眉显示页顶所在的章；`\textwidth` 按当前栏宽解释（`layout-landscape.tex`、`shared/twocolumn.tex`）。
- 扉页（用户确认）：三版保留同字号、同间距的居中标题区，配图区尺寸与作者到配图的间距统一，仅以外围留白适应纸张方向，使书名与配图的视觉分量一致。提交信息为眉题式三行，不用“·”串联；横版、代码版居中竖排；代码版书名后悬挂“（代码版）”，不参与居中（`shared/titlepage.tex`、`layout-<版本>.tex`）。
- 提交哈希链接（用户确认）：入口用 `\RepositoryURL` 给出仓库地址时，扉页的短哈希链接到 `<仓库地址>/commit/<短哈希>`；只有哈希可点，外观不变，有未提交修改时也链接，不写地址则不加链接。不另输出完整哈希：GitHub 能直接打开短哈希，日后与其他对象撞前缀的概率可以忽略，扉页的日期与提交说明也能定位提交（`shared/titlepage.tex`）。
- 仓库地址行（用户确认）：设了 `\RepositoryURL` 时，底部信息区首行为 Nerd Fonts 的 GitHub 标志 `oct-mark_github`（U+F408，GitHub 官方 Octicons 中的圆形标志）加去掉 `https://` 的地址，与日期同用等宽字体和次要灰，整行链接到仓库；标志与地址作为整体居中，不像“（代码版）”那样悬挂：标志是这一行的开头，悬挂会让整行看着偏左。没有提交信息时只显示这一行。地址用等宽字体：苹方的连字符过宽，像破折号（`shared/titlepage.tex`）。
- 底部信息区间距（用户确认）：地址行与提交信息之间的留白大于提交信息内部的留白，使眉题与它标注的两行成一组；眉题下不额外加距，避免眉题悬在两组之间。含未提交修改时，为高出数字且低于基线的标签细框补偿上下间距，使视觉留白与没有标签时接近（`shared/titlepage.tex`）。
- 结构：三版共用的实现放在 `shared/`，各版布局只放参数；代码版布局取值同横版，但单独维护。

另有两项实现选择：算子与 `\mathrm` 使用数学字体、`\text` 使用正文字体，以统一公式字形；⭐、🚩 映射到项目内的单色 Noto Emoji 字体，旧的 emoji 处理方式不再恢复。原因见 `shared/fonts.tex` 的注释与 `fonts/README.md`。

## 已知限制

- 未做实物打印验收；完整 PDF 没有逐页做视觉检查。
- 五级标题只完成了配置，正文尚未使用。
- 双栏版中，推导用的 `aligned` 整组不可拆分，可能在栏底留下空白；用户确认不处理。
- 分隔线恰在分页处时会排到下一页（栏）的顶端、紧贴页眉，像一条页眉线；用户确认暂不处理。
- 双栏栏宽较窄，较长的行内公式可能越出所在栏，通过编译警告与页面抽查识别；整书末轮日志中的 Overfull、Underfull 与 amsmath 等警告随正文变化，见 `scripts/README.md` 的“整书警告”。
