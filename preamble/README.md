# LaTeX 导言区配置

本目录集中管理宏包、版式与自定义接口。主文件在 `\documentclass` 之后直接加载所需文件，不增加 `setup.tex`，也不增加把各版参数合在一起的 `layout-common.tex`。2026-10-16 起，三版共用的排版实现放在 `shared/`，由各版布局文件载入；参数仍写在各版布局文件中。

| 文件或目录 | 职责与当前状态 |
| --- | --- |
| `packages.tex` | 已加载中文、OpenType 数学、图片、颜色、删除线、布局、标题、页眉、列表、目录、minted、tcolorbox 与超链接支持。 |
| `layout-portrait.tex` | 竖版参数：A4 纵向单栏，左右 20 mm、上下 15 mm（包含页眉页脚），字号、段落、标题样式与扉页版面。另有竖版专用的做法：一级标题前分页、页眉取当前一级标题、目录标题由 tocloft 居中。 |
| `layout-landscape.tex` | 横版参数：A4 横向双栏，12 mm 边距、8 mm 栏距，字号、段落、标题样式与扉页版面；双栏机制由 `shared/twocolumn.tex` 提供。设计参数与验证状态见文末。 |
| `layout-code.tex` | 代码版参数：目前取值与横版相同，但单独维护；入口由脚本以横版入口为模板生成。 |
| `shared/` | 三版共用的实现，不放参数：字体、配色、目录条目、双栏机制、代码样式、扉页。文件分工、载入顺序与参数接口见其 README。 |
| `mystyle.tex` | 已实现 `\Highlight`、`\InputCode`、`quoteblock` 与 `\Separator`。 |
| `fonts/` | 随项目保存的单色 Noto Emoji 静态字体与 OFL 许可，供三版的两个 Unicode 符号映射使用（`shared/fonts.tex`）。 |
| `tests/` | 当前已建立 `mystyle/`、`portrait/` 与共用资源 `fixtures/`；横版八份样张已建立，代码版五份样张已建立（均含扉页样张）。 |

入口仅保留文档类声明、下列三个导言区引用和标题／作者／日期等元信息（另有英文书名与扉页配图路径，代码版另有版本标记）；纸张、字体、字号、间距及编号等排版设置集中放在导言区文件中。ctex 加载前所需的临时字体选项由 `packages.tex` 管理。

三个入口共用 `packages.tex` 和 `mystyle.tex`，中间加载本版的 `layout-<版本>.tex`。各版布局文件只放本版参数（纸张、字号、间距、标题样式、栏距、扉页版面等）和本版专用的做法；三版共用的实现放在 `shared/`，由布局文件按顺序载入。横版入口直接引入 19 篇章节；代码版入口由生成脚本以横版入口为模板生成。三版均有扉页，由 `shared/titlepage.tex` 定义，各版布局用 `\TitlePageSetup` 给出版面参数。

仅在必要时修改公共宏包、接口或 `shared/` 中的文件。修改后对 mystyle 独立样张、三版全部样张及 PDF 检查回归，并重建三版完整 PDF 逐页比较。

`main-portrait.tex` 当前采用的加载顺序：

```latex
\input{preamble/packages.tex}
\input{preamble/layout-portrait.tex}
\input{preamble/mystyle.tex}
```

`\Highlight` 已按用户确认实现为 `#FFFF00` 背景、零内边距的不可拆分行内短语框。`\InputCode` 已实现浅灰标题栏、细灰边框、2 mm 圆角与跨页排版，左侧按语言显示单色 Nerd Font 图标，不显示右侧语言标签；代码区外观可通过各语言的 `\setminted[语言]{...}` 设置，续页不重复标题。`quoteblock` 已实现浅灰背景、左侧深灰竖线和跨页排版，竖线外侧至正文约一个中文字宽（`left=\ccwd`），其余三侧内边距 2 mm，并通过 `parbox=false` 保留所在版式的段间距与首行缩进；标准 `quote` 不变，当前不要求嵌套。`\Separator{}` 已实现为适应所在容器宽度的浅灰细线，线上下有间距，不强制换页。接口要求见根目录及 `contents/` 下的 `AGENTS.md`；每个接口均配有效果检验。

所有路径相对于项目根目录，不能假定加载本目录文件会改变工作目录。建议 XeLaTeX；minted 依赖 `latexminted`。宏包已加载不等于自定义接口或整本文档已经可编译。

按 2026-10-14 用户要求，竖版与横版分别在入口直接引入 19 篇章节，不创建 `contents/chapters.tex`。代码版改由脚本直接生成 `main-code.tex`，不创建 `contents/code-index.tex`。

从任意工作目录调用根目录脚本均会切换到项目根目录：

```sh
./run.sh             # 默认 portrait
./run.sh portrait
./run.sh landscape
./run.sh code
./run.sh all
./run.sh --help
```

产物分别为 `build/portrait/main-portrait.pdf`、`build/landscape/main-landscape.pdf`、`build/code/main-code.pdf`，辅助文件与 minted 缓存也按版本隔离。空入口提前报错；`all` 先检查三个入口，再按上述顺序构建，遇到失败停止。横版现可单独构建；代码版已实现，`all` 会先生成代码入口并依次构建三个版本。

## 横版设计与首轮实现（2026-10-14）

设计目标：兼顾 A4 打印查阅与电脑、平板阅读；与竖版共用正文和章节顺序，章节在栏内连续排版，页眉与目录参考竖版；封面暂不设计，首页直接为目录。横版布局不修改算法正文或代码原文件，不涉及仅代码版。

`layout-landscape.tex` 独立实现 A4 横向标准双栏（四边 12 mm 含页眉页脚，栏距 8 mm，栏宽 132.5 mm）、正文 10/14 pt、代码 8/10.5 pt、章节栏内连续、页眉显示页顶所在的一级标题（左栏顶端恰为新章时取该章，否则取页首延续的章）、通栏居中标题的双栏目录，以及沿用竖版的字体、数学、符号与代码配色。窄栏 `emergencystretch` 为 6em（曾讨论改回 3em，用户决定保持）；横版内 `\includegraphics` 将 `textwidth` 解释为当前栏宽（用户批准）。公共 `packages.tex`、`mystyle.tex` 未修改。

一、二、三级标题为苹方 Semibold 16/21、12/17、10.5/15 pt，前后留白依次为 10/5、8/4、6/3 pt；四、五级为 10/14 pt 苹方 Semibold，不大于三级标题。段首不缩进，段间距 `2pt plus 1pt minus 1pt`，列表紧凑。阅读顺序为左栏、右栏、下一页；栏底自然留白，不拉伸段距对齐，章末不平衡两栏；章首不强制换页或换栏，标题与后续首行同栏，连续空标题同样受保护。页眉为苹方 8/10 pt、`666666` 灰色、无横线，页码在页脚居中、样式相同；一页可含多个一级标题，目录页不显示章名。

目录单独起页，结束后正文另起新页；“目录”标题跨整页居中（苹方 Semibold 22/28 pt），条目双栏排列，末页自然留白。条目沿用竖版目录方案 A：一级苹方 Semibold 12/15 pt、无点线，前后留白 12/5 pt；二、三级宋体配 Latin Modern Roman，分别为 10.5/15、10/15 pt，`888888` 点线的点中心间距 9 pt、两端各留 3 pt；一级页码 11 pt，其余 10 pt，均为常规字重、右对齐。缩进为目录 Regular 字体 10 pt 下“中”实测宽度的 0/2/4 倍，与竖版一致。长条目续行与本级起点对齐，单条不跨栏，父条目与首个子条目尽量同栏。目录到三级，书签到五级并默认全部展开。
