# 导言区修改约定

适用于 `preamble/` 下的宏包、布局、共用实现、自定义接口与样张。结构、接口规格与设计决定见 `README.md`，共用实现的载入顺序与参数接口见 `shared/README.md`，样张与检查脚本见 `tests/README.md`。

## 分工

- `packages.tex`：只加载宏包并维护加载顺序；ctex 加载前所需的字体选项也放在这里。
- `layout-<版本>.tex`：只放本版参数（纸张、边距、栏距、字号、段落、标题样式、扉页版面）和本版专用的做法。三版各自维护；代码版取值目前与横版相同，但不引用横版布局。两份除注释外须逐行相同（`scripts/tests/test_layouts.py`），所以代码版只有扉页样张；要分开取值时，先加回代码版的其余样张，见 `tests/code/README.md`。
- `shared/`：只放三版共用的实现，不放参数，由各版布局按顺序 `\input`，入口不直接引用。某版需要不同取值时，增加参数或在该版布局中覆盖，不在共用文件里按版本分支（用户确认）。
- `mystyle.tex`：只有 `\Highlight`、`\InputCode`、`quoteblock`、`\Separator` 四个自定义接口。新增接口或改变外观须经用户确认。
- 命名：共用实现的命令、颜色和计数器以 `Book` 开头，expl3 变量用 `book` 模块名；供入口或样张调用的命令（`\EnglishTitle`、`\TitlePageImage`、`\EditionLabel`、`\RepositoryURL`、`\TitlePageReadCommit`、`\TitlePageSetup`）不加前缀。

## 文档维护

颜色、字号、边距、间距等视觉参数的具体取值只在 `.tex` 中维护；README 保留接口行为、设计理由与用户确认的取舍，不重复参数表（用户确认：视觉调整无需同步修改多处数值）。功能层级、字符码位和字体资源来源等必要信息不受此限制。

## 改动与验收范围

按实际影响分级验收（用户确认：小幅视觉调整不应承担全项目验证成本）。每次修改先运行快速检查，再按下表选择范围；发现异常时扩大检查。

| 改动 | 验收范围 |
| --- | --- |
| 颜色、边框、圆角、局部间距、扉页位置 | 编译并目视检查相关样张 |
| 正文字号、字体、纸张、页边距、栏宽等影响全书的参数 | 相关样张及功能检查；构建受影响版本整书，查看末轮警告并抽查典型页面 |
| 分页分栏机制、目录、共用实现重构 | 相关功能测试；构建受影响版本整书，查看警告并抽查内容与分页连接处 |
| 样张正文或 PDF 检查脚本 | 重新编译并检查涉及的样张；不因此要求重建整书 |
| 升级 minted、Pygments 或 TeX Live | 先删除 `build/` 与 `preamble/tests/build/` 下各输出目录中的 `_minted`、`_minted-*` 缓存，再运行 `scripts/check.sh --full`，目视检查代码配色与内容；缓存可能沿用升级前的高亮结果，且配色实现使用内部 token 接口 |

修改共用文件本身不触发三版整书或全部样张构建；根据具体行为影响选择版本和样张。`scripts/check.sh --full` 保留为需要全面样张回归时的入口。

不维护自动逐页精细比较、整书 PDF 越栏扫描及配套版心记录机制（用户确认：以编译警告和受影响页面目视检查控制维护成本）。应检查标题、颜色作用范围、缺字、重叠、溢出、代码内容及跨页跨栏；编译成功不替代这些验收。

## 样张与检查

- 每个自定义命令或环境在 `tests/` 都有可从根目录编译的效果检验；新增功能时补充功能场景；改变外观时查看相关样张。
- 样张只检验 `preamble/`，不引用 `contents/` 章节；产物只写入 `tests/build/`。
- 样张应覆盖中文及带空格的路径、多语言代码、跨页或跨栏。编译通过后仍要检查 PDF；改动后重新验证，历史结果不能作为新实现的证据。
- 每组样张的 PDF 检查都写在本组的 `check.py`，几版共用的断言放进 `tests/pdfcheck.py`。检查使用 `tests/pdfcheck.py` 的显式检查，不用裸 `assert`；几版内容相同的样张正文放在 `tests/fixtures/*-body.tex`。

- 自动回归只锁定内容完整性、功能与结构关系，不锁定具体字体名、字号、色值、间距或自然分页位置（用户确认：视觉调整通常不应要求修改测试）。精确外观用样张目视验收；改变功能约定时同步修改对应测试。边界样张按可用空间构造，并确认实际触发跨页、跨栏，不能仅删除固定页码断言而让场景失效。

## 字体与环境

- 字体缺失时报错，不静默替换；不复制字体、不改系统字体缓存、不硬编码用户字体路径。macOS 沙箱可能挡住字体服务，此时换到能访问系统字体的环境编译，不为此改用其他字体。
- `tests/mystyle/` 的样张使用 TeX Live 的 Fandol 字体；测试字体与检验用的默认值都不代表用户确认的设计。
- 不开启不受限 shell escape。
- 不恢复已撤下的实现，例如旧的 emoji 修复、各版独立的 `titlepage-<版本>.tex`。
