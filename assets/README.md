# 素材

本目录存放章节以外的素材文件，例如扉页配图，不放 `.tex` 代码。扉页外观代码在 `preamble/titlepage-portrait.tex`，章节图片仍放在 `contents/` 各大类的 `figures/`。

| 文件 | 用途 |
| --- | --- |
| `CL-logo-c4.png` | 竖版扉页的占位配图，由用户提供；1254 × 1254 像素，没有透明通道，透明棋盘格画在像素中。由 `main-portrait.tex` 的 `\TitlePageImage` 引用。 |

## 使用规则

- 路径相对于项目根目录，保留真实文件名，例如 `\TitlePageImage{assets/CL-logo-c4.png}`。入口不写 `\TitlePageImage` 或参数为空时，扉页中部留白；路径写错时编译报错。
- 扉页配图在页面中部宽 130 mm、高 110 mm 的区域内等比缩放并居中；标题区与底部提交信息的位置不随图片比例变化。
- 打印建议使用矢量 PDF；位图在成品尺寸下至少 300 dpi（宽 130 mm 约 1540 像素）。需要透明背景时，使用带透明通道的 PNG 或 PDF。
- 第三方素材需附来源或许可说明，与素材放在一起。
