# 素材

本目录存放章节以外的素材文件，例如扉页配图，不放 `.tex` 代码。扉页外观代码在 `preamble/titlepage-<版本>.tex`，章节图片仍放在 `contents/` 各大类的 `figures/`。

| 文件 | 用途 |
| --- | --- |
| `CL-logo-c4.png` | 三版扉页共用的占位配图，由用户提供；1254 × 1254 像素，没有透明通道，透明棋盘格画在像素中。由 `main-portrait.tex`、`main-landscape.tex` 的 `\TitlePageImage` 引用；代码版入口由 `scripts/generate-code.py` 的模板写入同一路径。 |

## 使用规则

- 路径相对于项目根目录，保留真实文件名，例如 `\TitlePageImage{assets/CL-logo-c4.png}`。入口不写 `\TitlePageImage` 或参数为空时，扉页中部留白；路径写错时编译报错。
- 扉页配图在页面中部的固定区域内等比缩放并居中：竖版为宽 130 mm、高 110 mm，横版与代码版为宽 110 mm、高 70 mm。标题区与底部提交信息的位置不随图片比例变化。更换配图时，横版入口与代码版生成模板中的路径须一起修改，生成器测试会检查两者是否一致。
- 打印建议使用矢量 PDF；位图在成品尺寸下至少 300 dpi（宽 130 mm 约 1540 像素）。需要透明背景时，使用带透明通道的 PNG 或 PDF。
- 第三方素材需附来源或许可说明，与素材放在一起。
